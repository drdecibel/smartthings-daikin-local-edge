# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-09-06

- Initial community release.
- Local UDP discovery and HTTP control for BRP069B4x adapters.
- Power, operating mode, heating/cooling setpoints, fan speed and swing control.
- Indoor/outdoor temperature and compressor-based operating state.
- Configurable polling interval and optional IP/hostname override.
- Automated Lua, YAML and core-behavior validation with GitHub Actions.
- GPL-3.0-or-later licensing with attribution to `drdecibel`.
